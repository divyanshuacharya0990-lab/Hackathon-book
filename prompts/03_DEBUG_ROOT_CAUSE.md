Failure: [EXACT LOG/TEST/OBSERVATION]. Expected: [RESULT]. Current branch/SHA: [IF KNOWN]. Reproduce first where practical; inspect recent diff and failing dependency path. Form a cause hypothesis supported by observed evidence, then implement the smallest safe fix.
